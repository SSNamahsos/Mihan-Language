# درس ۱۴ — اشتراک برنامه به‌صورت یک فایل (mihan build)

برنامه‌ای نوشته‌اید و حالا می‌خواهید آن را به کسی بدهید که اسم میهن را هم نشنیده است.
`mihan build` **یک فایل** می‌سازد که هم موتور اجرای میهن و *هم* برنامه‌ی شما را در خودش دارد.
طرف مقابل فقط اجرایش می‌کند.

## ۱۴.۱ ساده‌ترین ساخت

</div>

```mihan file=salam/salam.mhn
naam = khanak("esmet chie? ")
chap_khat "salam " + naam + "!"
```

```
mihan build salam/salam.mhn
```

<div dir="rtl">

در ویندوز فایل `salam.exe` و در لینوکس فایل `salam` ساخته می‌شود. اجرایش کنید:

</div>

```
./salam            # Linux
salam.exe          # Windows
```

<div dir="rtl">

هر چیزی که بعد از اسم بیاید به برنامه‌ی شما می‌رسد، پس `arghoman()` مثل درس ۹ کار می‌کند.

## ۱۴.۲ انتخاب سیستم: --os و --arch

از هر سیستمی می‌توانید برای سیستم دیگر بسازید:

| چه می‌خواهید | دستور |
|---|---|
| ویندوز، کامپیوتر ۶۴ بیتی | `mihan build app.mhn --os windows` |
| ویندوز روی ARM | `mihan build app.mhn --os windows --arch arm64` |
| لینوکس، کامپیوتر ۶۴ بیتی | `mihan build app.mhn --os linux` |
| لینوکس روی ARM (رزبری‌پای ۴/۵، سرورهای ARM) | `mihan build app.mhn --os linux --arch arm64` |

`-o name` اسم فایل خروجی را تعیین می‌کند. ساختن برای سیستم دیگر به موتور اجرای همان سیستم
نیاز دارد که همراه میهن در پوشه‌ی `runtimes` کنار `mihan` می‌آید (`mihan-linux-amd64`،
`mihan-linux-arm64`، `mihan-windows-amd64.exe`، `mihan-windows-arm64.exe`). به Go **نیازی
ندارید**. اگر موتورها را جای دیگری نگه می‌دارید، `MIHAN_RUNTIMES` را روی آن پوشه بگذارید یا
یکی را با `--base path/to/runtime` بدهید.

## ۱۴.۳ برنامه‌های پنجره‌ای: --window

برنامه‌ای که با `baza_bgo` (درس ۱۲) پنجره باز می‌کند یک *اپ* است، و در ویندوز یک اپ نباید
کنارش یک پنجره‌ی سیاه کنسول داشته باشد:

</div>

```
mihan build counter.mhn --os windows --window     # no console window
mihan build tool.mhn --os windows                  # a script: keeps its console
```

<div dir="rtl">

`--window` را فقط برای برنامه‌هایی به کار ببرید که پنجره نشان می‌دهند؛ اسکریپتی که با آن
ساخته شود جایی برای چاپ کردن ندارد. در لینوکس کنسولی برای پنهان کردن نیست، پس این گزینه
آن‌جا چیزی را عوض نمی‌کند.

وقتی کاربر پنجره‌ی اپ را می‌بندد، برنامه هم متوقف می‌شود: هیچ سروری در پس‌زمینه روشن نمی‌ماند.

در لینوکس پنجره در Chrome، Chromium، Edge یا Brave در *حالت برنامه* (پنجره‌ای بدون نوار
آدرس) یا در یک پنجره‌ی جدای Firefox باز می‌شود. اگر هیچ‌کدام نصب نباشد، آدرس با `xdg-open`
در مرورگر پیش‌فرض باز می‌شود؛ در این حالت میهن نمی‌فهمد پنجره کی بسته شد، پس برنامه تا وقتی
خودتان متوقفش نکنید روشن می‌ماند. با `MIHAN_BROWSER=/path/to/browser` خودتان مرورگر را
انتخاب کنید.

## ۱۴.۳ب سایت‌هایی که مرورگر را باز می‌کنند: --open-browser

یک سایت (برنامه‌ای که `serva_bgo` را صدا می‌زند) اگر به `.exe` تبدیل شود، در حالت عادی
بی‌صدا شروع می‌شود و منتظر می‌ماند کسی آدرسش را تایپ کند. با `--open-browser`، دوبار کلیک
روی فایل، سایت را به‌محض آماده شدن در مرورگر پیش‌فرض باز می‌کند:

</div>

```
mihan build examples/pro-sites/negar/negar.mhn --os windows --open-browser -o Negar.exe
```

<div dir="rtl">

اگر می‌خواهید جایی برای دیدن آدرس و متوقف کردن سایت با Ctrl+C داشته باشید، کنسول را نگه
دارید (بدون `--window`)؛ برای سایتی که باید کاملاً بدون کنسول اجرا شود `--window` را اضافه
کنید (و از Task Manager متوقفش کنید).

## ۱۴.۴ چه چیزهایی داخلش می‌رود

کل پوشه‌ی فایلی که می‌سازید داخلش می‌رود: فایل‌های `.mhn` دیگری که `biar` می‌کنید، پوشه‌ی
صفحه‌های `safhe/`، عکس‌ها و CSS. چیزهایی که کنار گذاشته می‌شوند: پوشه‌های `dade/` (داده‌ای
که برنامه‌تان می‌نویسد)، پوشه‌های مخفی مثل `.git` و فایل‌های `.exe` دیگر. پس هر برنامه را در
پوشه‌ی جداگانه‌ی خودش نگه دارید.

</div>

```
mihan build examples/pro-sites/negar/negar.mhn --os windows --window -o Negar.exe
```

<div dir="rtl">

فایل در اولین اجرا برنامه‌ی شما را در یک پوشه‌ی مخصوص خودش باز می‌کند:

* ویندوز: `%LOCALAPPDATA%\mihan-apps\<name>\`
* لینوکس: `~/.cache/mihan-apps/<name>/`

این کار برای هر ساخت فقط یک بار انجام می‌شود. داده‌ای که برنامه کنار خودش می‌نویسد (مثلاً
`dade/` با استفاده از `poshe_barname()`) همان‌جا می‌ماند و با ساخت دوباره از بین نمی‌رود.

## تمرین‌ها

۱. شمارنده‌ی کلمه‌های درس ۹ را برای سیستم خودتان بسازید و با یک اسم فایل بعد از آن اجرایش کنید.
۲. برنامه‌ی شمارنده‌ی `examples/windows/counter.mhn` را یک بار با `--window` برای ویندوز و یک
   بار بدون آن برای لینوکس بسازید و اندازه‌ی دو فایل را مقایسه کنید.
