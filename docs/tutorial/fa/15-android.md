# درس ۱۵ — برنامه‌ی شما روی گوشی اندروید (mihan build --os android)

> **خلاصه:** `mihan build app.mhn --os android` یک فایل `.apk` می‌سازد که روی گوشی
> اندروید نصب می‌شود. برنامه‌ای که پنجره باز می‌کند (`baza_bgo`) یا سرور راه می‌اندازد،
> در خودِ برنامهٔ گوشی نشان داده می‌شود؛ برنامه‌ای که فقط چاپ می‌کند، نوشته‌هایش را نشان می‌دهد.

همان برنامه‌ای که در ویندوز یک پنجره می‌شود (درس ۱۲)، روی گوشی یک اپ می‌شود. به هیچ چیز
اضافه‌ای نیاز ندارید: نه Android Studio، نه Java، نه SDK. خود `mihan` فایل APK را می‌نویسد و
امضا می‌کند.

## ۱۵.۱ ساختن APK

</div>

```mihan file=shomar/shomar.mhn norun
shomar = 0

funct safhe()
    bargard $"<h1 style='font-size:4rem'>{shomar}</h1><a href='/bishtar'>+1</a>"

funct pasokh(darakht)
    agar darakht["path"] == "/bishtar"
        shomar += 1
    bargard {"vaziat": 200, "matn": safhe()}

funct baz_kon()
    baza_bgo(serva_khod())

serva_bgo(0, pasokh, baz_kon)
```

```
mihan build shomar/shomar.mhn --os android
```

```
built shomar.apk (android/arm64, package org.mihan.app.shomar, 1 files, 3.4 MB, signed with a debug key)
```

<div dir="rtl">

| گزینه | معنی |
|---|---|
| `--arch arm64` | برای گوشی‌ها (پیش‌فرض اندروید) |
| `--arch amd64` | برای شبیه‌ساز اندروید روی کامپیوتر |
| `--arch all` | هر دو در یک APK (حجیم‌تر) |
| `--name "Shomarande"` | اسم زیر آیکون (پیش‌فرض: اسم فایل) |
| `--package org.example.shomar` | شناسه‌ی اپ (پیش‌فرض: `org.mihan.app.<file name>`) |

## ۱۵.۲ نصب روی گوشی

`shomar.apk` را به گوشی منتقل کنید و بازش کنید. اندروید از شما می‌خواهد نصب اپ از آن منبع را
مجاز کنید، چون اپ از فروشگاه نیامده است. یا اگر گوشی با USB وصل است و *USB debugging*
روشن است:

</div>

```
adb install shomar.apk
```

<div dir="rtl">

اپ مستقیم با برنامه‌ی شما باز می‌شود. دکمه‌ی برگشت یک صفحه به عقب می‌رود و بستن اپ برنامه را
متوقف می‌کند.

## ۱۵.۳ داخلش چه اتفاقی می‌افتد

* فایل APK یک اپ کوچک اندروید (یک WebView تمام‌صفحه) دارد و به‌عنوان کتابخانه‌ی بومی‌اش،
  **موتور اجرای لینوکس برای پردازنده‌ی گوشی همراه با برنامه‌ی شما که به انتهایش چسبیده**،
  دقیقاً مثل ساخت لینوکس در درس ۱۴.
* اپ آن برنامه را اجرا می‌کند. وقتی برنامه پنجره باز می‌کند یا سرور راه می‌اندازد، اپ همان آدرس
  را نشان می‌دهد. اگر فقط چاپ کند، اپ چیزهایی را که چاپ کرده نشان می‌دهد، پس برنامه‌های
  `chap_khat` هم کار می‌کنند. `khanak` (ورودی تایپی) کار نمی‌کند: گوشی ترمینالی برای تایپ ندارد.
* فایل‌هایی که برنامه می‌نویسد در پوشه‌ی خصوصی خود اپ روی گوشی ذخیره می‌شوند.

## ۱۵.۴ امضا

اندروید فقط اپ‌های امضاشده را نصب می‌کند. `mihan` با یک **کلید دیباگ** امضا می‌کند که بار اول
می‌سازد و در پوشه‌ی تنظیمات شما نگه می‌دارد (`~/.config/mihan/android-debug.pem` در لینوکس،
`%AppData%\mihan\android-debug.pem` در ویندوز). این فایل را نگه دارید: یک به‌روزرسانی فقط
وقتی روی اپ قبلی نصب می‌شود که با همان کلید امضا شده باشد. اپی که با کلید دیباگ امضا شده برای
گوشی‌های خودتان و دوستانتان مشکلی ندارد. برای انتشار در فروشگاه باید دوباره با کلید انتشار
خودتان امضایش کنید (مثلاً با `apksigner` از Android SDK).
