# درس ۱۳ — ابزارها: test، check، fmt و VS Code

> **خلاصه:** `mihan test` بررسی می‌کند برنامه همان چیزی را چاپ کند که گفته‌ای، `mihan check` اشتباه‌ها را بدون اجرا پیدا می‌کند،
> و افزونه‌ی VS Code تکمیل خودکار و راهنما می‌دهد.

## ۱۳.۱ گفتن این‌که برنامه باید چه چیزی چاپ کند

یک بلوک `#khoroji` بالای فایل بگذارید: به‌ازای هر خط خروجی یک خط `#|`.
`mihan test file.mhn` آن را اجرا و مقایسه می‌کند.

</div>

```mihan
#khoroji
#| 42
#| salam

chap_khat 6 * 7
chap_khat "salam"
```

```output
42
salam
```

```
> mihan test javab.mhn
salam  javab.mhn                                      kharch

1/1 sabet. Mihan 0.2.0
```

<div dir="rtl">

`mihan test` بدون اسم فایل، همه‌ی فایل‌های `.mhn` داخل `docs/`، `tests/` و `examples/` را اجرا می‌کند.

## ۱۳.۲ دستورهای دیگر

| دستور | کارش |
|---|---|
| `mihan run x.mhn` | اجرای یک برنامه |
| `mihan check x.mhn` | پیدا کردن اشتباه‌ها بدون اجرا |
| `mihan fmt x.mhn` | مرتب کردن فایل به شکل استاندارد |
| `mihan repl` | امتحان کردن خط‌به‌خط |
| `mihan doc` | کل زبان در یک صفحه |
| `mihan new myapp` | شروع یک پوشه‌ی پروژه‌ی تازه |
| `mihan build app.mhn` | ساختن **یک فایل `.exe`** که برنامه را در خودش دارد (پایین‌تر را ببینید) |

درس ۱۴ `mihan build` را کامل نشان می‌دهد.

## ۱۳.۳ VS Code

افزونه را نصب کنید (`mihan-0.7.8.vsix`: *Extensions → … → Install from VSIX*).
بعد در هر فایل `.mhn` این‌ها را دارید:

* **تکمیل خودکار** برای همه‌ی کلمه‌های کلیدی (فینگلیش و انگلیسی)، همه‌ی تابع‌های آماده همراه
  با راهنمای یک‌خطی‌شان، و متغیرها، تابع‌ها و کلاس‌های خودتان. تابع‌های خودتان پارامترهایشان
  را نشان می‌دهند.
* **قطعه‌کدها (Snippets)**: `funct`، `agar`، `har`، `darghan` یا `koshish` را تایپ کنید و
  Enter بزنید تا کل ساختار نوشته شود. `m-api`، `m-page`، `m-window`، `m-script` و
  `m-khoroji` یک سرور، صفحه، برنامه‌ی پنجره‌ای، اسکریپت یا بلوک تست کامل می‌نویسند.
* **راهنمای امضا**: بعد از اسم یک تابع `(` بزنید تا پارامترهایش را ببینید.
* **نگه داشتن ماوس** روی هر کلمه تا معنی‌اش را ببینید.
* **اشتباه‌ها** همان‌طور که تایپ می‌کنید، با پیام فینگلیش زیرشان خط کشیده می‌شود.
* **Ctrl+کلیک** برای پریدن به جایی که یک اسم ساخته شده، و **مرتب‌سازی هنگام ذخیره**.

افزونه `mihan.exe` را در خودش دارد، پس حتی قبل از اجرای `mihan install` هم کار می‌کند.

## ۱۳.۴ قدم بعدی

* `mihan doc`: همه‌ی کلمه‌ها و تابع‌های آماده.
* `examples/`: اسکریپت‌ها، سایت‌ها و برنامه‌های پنجره‌ای که در هر ساخت آزمایش می‌شوند.
* `examples/pro-sites/`: سه وب‌سایت کامل و خوش‌ظاهر.
